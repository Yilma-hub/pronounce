      Pronunciation scores come from Microsoft Azure Speech. It listens to each word and each sound and scores it from 0 to 100, without needing the book text. The free tier covers several hours of reading each month.

      Get a free key (one time)

      1. Go to portal.azure.com and sign up (a card is needed to verify, the free tier is not charged).
      2. Search for Speech service and tap Create.
      3. Pick any resource group, a region such as East US, and the pricing tier Free F0. Create it.
      4. Open the resource, go to Keys and Endpoint, copy KEY 1 and the Location/Region (for example eastus).
      5. Paste them below and tap Save.

      The key is saved only on this phone. Never put it inside the index.html file on GitHub, because anyone could read it there.
